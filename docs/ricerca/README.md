# Ricerca

- `simulazioni/rischio_per_trade.py`: Monte Carlo del drawdown in funzione del rischio per trade (tre scenari di vantaggio).
- `simulazioni/circuit_breaker.py`: confronto tra politiche di riduzione del rischio e soglie di blocco.
- I file `*_output.txt` contengono i risultati (seed fissi, riproducibili).
Le conclusioni sono riportate in `knowledge/rischio/`.
